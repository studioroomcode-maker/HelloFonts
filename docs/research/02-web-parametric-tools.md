# 웹·간편·손글씨·매개변수형 폰트 도구 조사

공식 사이트·문서·리뷰를 바탕으로 조사했습니다. 직접 써 보고 검증한 것은 아닙니다.
서비스를 종료한 곳: Prototypo(2020), Fontark, 온글잎(2023).

## Fontra (Black[Foundry], 구글 후원) — 우리와 가장 가까운 웹 편집기
오픈소스(GPL-3.0)이고 브라우저에서 동작하며, 가변 폰트 중심으로 설계됐습니다. 대형 CJK 프로젝트를 위해 만들어졌습니다. https://github.com/fontra/fontra

- 수만 글리프 규모를 지원합니다. 겹겹이 들어간 가변 컴포넌트도 빠르게 실시간 보간합니다.
- 최대 15명이 동시에 협업할 수 있습니다(서버 필요).
- **글리프 자체의 축**: 자모 같은 부품이 폭·높이 같은 자기 축을 갖습니다. 이동·회전·크기·기울임도 각각 따로 보간합니다. → 우리의 "자모를 배치 틀에 넣기" 방식과 그대로 맞아떨어집니다.
- 패널 구성
  - 미리보기 문장: 캔버스 위에서 문장 전체를 편집할 수 있습니다.
  - 디자인 공간 슬라이더
  - 참조 폰트를 글자 뒤에 깔기
  - 글리프 메모
- **관련 글리프 패널**: "이 부품을 쓰는 글자", "이 글자가 쓰는 부품", 대체 글자, 유니코드 분해를 보여 주고, 누르면 그 글자로 이동합니다.
- 기타 기능: 글리프 전체 보기(묶음·분류), 배경 이미지와 레이어, 커닝 도구, OpenType 기능 편집기와 셰이핑 디버거
- 파일: UFO, .glyphs, TTF, OTF를 읽고 씁니다.
- 약점
  - 전문가용이라 화면이 복잡하고 초보자 안내가 없습니다.
  - 뼈대·스트로크 엔진이 없습니다.

## Glyphr Studio v2 — 무료 웹 벡터 편집기(취미용)
- 기능: 컴포넌트, 합자, 커닝 그룹, 여러 글자를 한 번에 바꾸는 "전체 작업"
- 파일: OTF, TTF, WOFF, SVG 폰트를 가져오고, OTF, TTF, WOFF, WOFF2, SVG로 내보냅니다.
- 약점: 가변 폰트, 마스터, CJK를 지원하지 않고 외곽선 편집만 됩니다.

## FontStruct — 격자 위 "벽돌"로 조립하는 웹 도구
- 숫자 키로 벽돌을 고릅니다.
- 팔레트의 벽돌에 새 벽돌을 끌어 놓으면 그 벽돌이 쓰인 곳 전체가 한 번에 바뀝니다.
- 이어지는 벽돌 58종(단선·2선·3선 획, 획 끝)을 제공합니다.
- 기본 모드는 단순하게 두고, 원하는 사람만 전문가 모드를 켭니다.
- 공개 갤러리에서 남의 글꼴을 복제해 고쳐 쓸 수 있습니다.
- 약점: 기하학적인 모양만 가능하고, 굵기 대비가 없습니다.

## Prototypo (종료) — 뼈대 기반 매개변수형 웹앱
- 템플릿 4종(Fell, Grotesk, Elzevir, Spectral)에 슬라이더가 30개 넘게 있습니다.
  - 주요 슬라이더: 두께, 폭, x높이, 기울기, 열림, 둥근 정도, 세리프 세부
- 개별화: 특정 글자나 글자 묶음에만 매개변수를 덮어쓸 수 있습니다.
- v2 추가 기능
  - 뼈대 점 편집
  - 붓 위치·각도·필압
  - 세리프 모양 같은 부품 교체
  - "#FixMe" 도구
- 크롬 확장으로 아무 웹사이트에서나 실시간 미리보기를 할 수 있고, OTF로 내보냅니다.
- 약점: 라틴 문자만 지원했고, 사업이 실패해 서비스가 종료됐습니다.

## Metaflop — Metafont 기반 웹 변조기
- 슬라이더 묶음
  - 치수: 단위 폭, 펜 폭
  - 비율: 대문자, 가로줄, 어센더, 디센더, x높이
  - 모양: 가로·세로 증가, 대비, 둥근 정도(superness), 기울기
  - 광학 보정: 열림, 모서리, 오버슈트, 가늘어짐
- 슬라이더마다 --/−/+/++ 버튼이 있습니다.
- 보기: 해부도, 글리프, 차트, 타자기(16~96px)
- 초보/전문가 전환, 무작위 생성("flop it!"), 되돌리기
- 약점: 서버에서 렌더링해서 미리보기가 느리고, 라틴 문자만 됩니다.

## Calligraphr — 손글씨 템플릿을 스캔해 폰트 만들기
- 흐름
  1. 칸 크기를 조절할 수 있는 템플릿을 인쇄합니다(도움선 선택).
  2. 손으로 쓴 뒤 휴대폰으로 찍으면, 모서리 표식을 기준으로 정렬됩니다.
  3. 업로드한 뒤 글자별로 기준선·크기를 맞추고 정리합니다.
- 템플릿을 여러 번 써서 올리면 같은 글자의 변형이 쌓이고, 무작위로 번갈아 나오는 폰트가 됩니다.
- 약점: 글자 수가 많아서 한국어·일본어는 지원하지 않습니다.

## Fontself Maker — 일러스트레이터·포토샵 확장
- 도형을 패널에 끌어 넣으면 글자가 됩니다.
- **클릭 한 번으로 모든 글자의 자간·커닝을 자동 설정**합니다(Smart Metrics).
- 컬러 폰트, 합자, 대체 글자를 지원합니다.
- 약점: Adobe CC가 필요하고, 매개변수로 조절하는 기능이 없습니다.

## Fontark (종료) — 뼈대만 그리면 외곽선이 실시간 생성되는 웹 편집기
- **SmartX 점**: 모든 글자가 공유하는 점입니다. 여기에 뼈대 점을 묶어 두면 한 번 끌어서 전체 비율이 바뀝니다.
- 약점: 서비스가 종료되면서 사용자 작업물을 되살릴 방법이 사라졌습니다.

## BitFontMaker2 — 무료 픽셀 폰트 편집기
- 마우스만으로 그리고, 클릭 한 번으로 TTF를 만듭니다.
- 이름 뒤에 Thin/Regular/Bold를 붙여 패밀리를 구성합니다.
- 갤러리에 올릴 때 라이선스를 고릅니다.

## AI 손글씨 폰트 서비스
- **네이버 클로바**: 손글씨 256자로 11,172자 전체를 생성합니다.
- **온글잎**: 최소 12자로 한글·영문·기호를 생성했습니다(2023년 종료).
- 교훈: "조금만 쓰면 나머지는 만들어 준다"는 약속에는 수요가 확실합니다. 우리는 AI 없이 자모 조합으로 같은 약속을 할 수 있습니다.

## 가져올 아이디어 (우선순위순)
1. 묶음별 전체 스타일 슬라이더 + 초보/전문가 전환 + ±버튼 (Metaflop, Prototypo)
2. 빈 캔버스 대신 프리셋에서 시작 (Prototypo 템플릿)
3. 글자·묶음별 매개변수 덮어쓰기. 예: 종성 전체, 특정 자모 묶음 (Prototypo 개별화)
4. 모든 뼈대가 공유하는 기준점·치수 → 한 번 끌어 전체 비율 변경 (Fontark SmartX)
5. 항상 보이는 편집 가능한 미리보기 문장, 문장 안에서 바로 글자 편집 (Metaflop, Fontra)
6. 관련 글리프 패널: 이 자모를 쓰는 음절, 분해, 대체 글자, 누르면 이동 (Fontra)
7. 초성·중성·종성·배치 틀별로 묶고 거르는 글리프 전체 보기 (Fontra)
8. 인쇄 템플릿 → 휴대폰 사진(모서리 표식) → 배경 참조층 자동 배치 (Calligraphr)
9. 손글씨 변형을 문맥 대체로 번갈아 쓰기 (Calligraphr)
10. "몇 자만 쓰면 나머지는 자동" — 최소 샘플로 자모 엔진 구동 (클로바, 온글잎)
11. 획 끝·세리프 부품 교체 → 쓰인 곳 전체에 적용 (FontStruct, Prototypo)
12. 클릭 한 번으로 자동 자간·커닝 (Fontself)
13. 매개변수 양끝값으로 패밀리·가변 폰트 내보내기 (Fontra, BitFontMaker2)
14. 무작위 생성 + 확실한 되돌리기 (Metaflop)
15. 서버에 기대지 않는 로컬 저장·파일 백업 (Prototypo·Fontark·온글잎의 서비스 종료로 작업물이 사라진 사례에서 얻은 교훈)
