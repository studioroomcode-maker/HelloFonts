# 한글·CJK 폰트 제작 방식 조사

공개 자료·논문·기사 기준 조사 (직접 검증 아님).

## 1. 벌수와 자모 배치 — 실무 표준

**8×4×4벌 체계** (조합형 표준, https://kldp.org/node/39679, https://brunch.co.kr/@font/15)
- **초성 8벌**
  - 받침 없음: ① ㅏㅐㅑㅒㅓㅔㅕㅖㅣ ② ㅗㅛㅡ ③ ㅜㅠ ④ ㅘㅙㅚㅢ ⑤ ㅝㅞㅟ
  - 받침 있음: ⑥ 세로모음 ⑦ ㅗㅛㅜㅠㅡ ⑧ 섞임모음
- **중성 4벌**: {초성이 ㄱ·ㅋ인가 아닌가} × {받침 유무}. ㄱ·ㅋ은 다리가 사선이라 모음 모양이 달라진다.
- **종성 4벌**: 모음에 따라 나뉜다. ① ㅏㅑㅘ ② ㅓㅕㅚㅝㅟㅢㅣ ③ ㅐㅒㅔㅖㅙㅞ ④ ㅗㅛㅜㅠㅡ

**우리 12배치와 비교**
- 초성 기준으로 보면 표준은 V·VL·VV를 한 벌로 묶는다.
- 대신 H를 ㅗㅛㅡ와 ㅜㅠ로 나눈다. ㅜㅠ의 기둥이 아래로 내려가 초성 아래 공간을 차지하기 때문이다.
- C도 ㅘㅙㅚㅢ와 ㅝㅞㅟ로 나눈다. ㅢ는 섞임모음 쪽에 들어간다.
- 우리에게 없는 두 가지 문맥이 있다: **ㄱ·ㅋ 뒤 모음 변형**, **모음별 종성 변형**.

**그 밖의 참고 사항**
- 본고딕(Source Han Sans)은 옛한글 500자를 초성 6·중성 2·종성 4벌로 조합한다.
- 실제 디자인은 벌수 표를 넘어선다. 초성 모양과 받침 유무에 따라 모음 길이를 조정하고, 조합마다 따로 손본다 (https://brunch.co.kr/@font/62).
- 탈네모꼴은 자리에 상관없이 자모 모양이 하나라서 각 1벌로 11,172자를 만들 수 있다.

**제작사 공정**
- 윤디자인: 대표 글자 5~10자 → 문장 시험 20~30자 → 완성형 2,350자(숙련자 약 1개월) → 앱에서 시험 → 영문·숫자 (https://www.yoondesign-m.com/117)
- 산돌: 글꼴 하나에 4개월~1년. 지금은 AI가 생성하고 디자이너가 검수해 시간을 약 60% 줄였다.
- Glyphs 권장 방식: 6가지 구조 유형마다 최소 1음절을 손으로 디자인한 뒤 문맥 변형을 추가하고, 8×8 CJK 격자를 쓴다.

**측정 가능한 공간 요소** (한글 분류 연구, https://www.aodr.org/_PR/view/?aidx=37519&bidx=3752)
- 네 범주: 골격, 공간, 굵기, 형태
- 구체적인 측정값: 중심선, 첫닿자 높이, 받침닿자 높이, 곁줄기 높이, 닿자 너비, 장체/평체, 접합 형태, 자소 비례

## 2. 도구
- **Glyphs**
  - "Hangul Composition Groups": 변형 묶음과 규칙으로 "어디에 어떤 자모를 쓸지"를 정하는 매개변수. 거의 문서화되어 있지 않다.
  - 스마트 컴포넌트는 원래 CJK용으로 만들어졌다.
- **Fontra**: 오픈소스 웹 편집기. 가변 컴포넌트 방식이 우리 구조와 가장 가깝다.
- **METAFONT 기반 구조적 한글 생성기** (권·손·최·정, 정보과학회 2016): 매개변수를 바꾸면 획과 자모의 크기·위치가 다시 생성된다.
- **StemFont** (최·이·정, 글짜씨 2021): 외곽선 제어점에 속성을 붙이고 매개변수 수식으로 굵기와 스타일을 바꾸는 웹 서비스. **우리 방식과 가장 가까운 선행 연구.**
- 참고 자료: 한글꼴큰사전 https://hanfont.hangeul.go.kr/

## 3. 스타일별 매개변수 후보
형태소 용어: 부리, 맺음, 꺾임, 굴림, 곁줄기, 짧은 기둥, 상투, 꼭지·점, 덧줄기, 내림점, 삐침, 이음줄기

- **명조**
  - 대비(가로 ÷ 세로 굵기)
  - 부리: 각도·길이·크기
  - 맺음: 크기·각도
  - 세로줄기 끝: 왼쪽 아래로 가늘어짐
  - 꺾임: ㄱ·ㄴ 모서리의 어깨 반경
  - ㅅ·ㅈ·ㅊ 삐침·내림의 곡률과 가늘어짐
  - 곁줄기: 점 모양
  - **꼭지이응·ㅎ 꼭지**: 켜기/끄기, 높이, 각도
  - ㅇ의 굵기 분포 각도
  - 중심선: 오른쪽 세로 기둥에 맞춤
  - ㅈ·ㅊ 모양: 갈래형 또는 꺾임형
- **고딕**
  - 민부리. 거의 일정한 굵기이되 가로획을 약간 가늘게
  - 획 끝: 평평함 / 둥긂 / 사선
  - 이음부 잉크 트랩
  - 글자 면 크기
  - 초성·받침 높이 비율, 곁줄기 높이
  - 기하학적 중심선
- **손글씨**
  - 기울기
  - 점 흔들림, 음절별 크기·기준선·회전 흔들림 (시드 기반)
  - **탈네모 전환**
  - 필압에 따른 끝 가늘어짐
  - 이음줄기
- **붓글씨**
  - 획 위치별 필압 곡선: 기필(시작) 굵게 → 행필(중간) 가늘게 → 수필(끝)
  - 갈필 질감
  - 궁체(오른쪽 기둥 정렬) / 민체
  - 겹치는 부분 진하게

## 4. AI·자동 생성
- **네이버 클로바 나눔손글씨**: 손글씨 약 256자 → OCR → 대량 손글씨로 사전 학습한 모델이 11,172자 생성. 109종 공개.
- **DM-Font** (ECCV'20): 28자로 모든 자소를 덮을 수 있고, 실험에는 참조 30자를 썼다.
- **LF-Font** (AAAI'21): 참조 4~8자.
- **MX-Font** (ICCV'21): 여러 언어 사이의 생성에 강하다.
- **CKFont**: 28자, GAN 기반.
- **SKFont**: 뼈대 기반.
- **DK-Font** (2025): 한 장으로 생성하는 확산 모델이지만, 결과는 128px 비트맵이다.
- **현실적 결론**
  - 연구 모델의 결과는 픽셀 이미지라 다시 벡터로 바꿔야 한다.
  - 실무에서는 산돌처럼 디자이너가 전부 검수한다.
  - 빌려 올 만한 발상: **약 28자면 모든 자소를 덮는다.** 사용자 샘플로 픽셀을 생성하는 대신, 스타일 엔진 매개변수나 자모별 뼈대 보정값을 맞추는 데 쓴다.

## 5. 패키징
- **용량**
  - 완성형 2,350자 + 영문: TTF 1.9MB, WOFF 686KB. WOFF2는 약 30% 더 작다.
  - 가변 합성(VARC)은 11,000음절·2굵기 한글 폰트를 92% 줄이지만 아직 지원이 넓지 않다.
  - 일반 TrueType 합성 글리프(자모 참조 + 위치)만 써도 크기가 크게 준다.
- **겹침**: 뼈대를 획으로 칠하면 획끼리 겹친다. 내보낼 때 글자마다 합치거나, 자모 단위 합성으로 낸다.
- **힌팅**: 11,000자 규모의 CJK 폰트는 보통 힌팅 없이 내거나 자동 힌팅만 가볍게 한다 (출처 미확인, 추정).
- **이름 테이블**: 플랫폼 3/1에 영어(0x0409)와 한국어(0x0412) 이름을 넣는다(nameID 1, 2, 4, 16, 17). PostScript 이름(nameID 6)은 ASCII로.
- **OS/2 테이블**
  - ulCodePageRange1: bit 19 (949 완성형), bit 21 (1361 조합형)
  - ulUnicodeRange: bit 28 (한글 자모), bit 52 (호환 자모), bit 56 (한글 음절), bit 48 (CJK 기호)
- **세로 메트릭**
  - sTypoAscender/Descender를 한자 em 상자와 같게(예: 880 / −120, UPM 1000)
  - USE_TYPO_METRICS 켜기, BASE 테이블
  - 세로쓰기를 지원하려면 vhea·vmtx·vert
- **포함 범위**
  - 자동 조합이므로 기본은 11,172자 전체, 웹용으로 2,350자 선택지를 둔다.
  - 호환 자모 U+3131–318E는 반드시 넣는다(입력기가 조합 중에 낱자를 표시한다).
- **옛한글 기능**: 현대 한글에는 ccmp·ljmo·vjmo·tjmo가 필요 없다. 셰이퍼가 L+V+T를 완성형 음절로 합친다.

## 가져올 아이디어 (우선순위순)
1. 초성 문맥 세분화: H → ㅗㅛㅡ / ㅜㅠ, C → ㅘㅙㅚㅢ / ㅝㅞㅟ
2. ㄱ·ㅋ 초성 뒤의 모음 변형 (받침 유무 포함)
3. 모음 묶음별 종성 변형 (ㅏㅑㅘ / ㅓㅕㅚ… / ㅐㅔ… / ㅗㅜ…)
4. 고정 배치 틀 대신 **규칙 표** (문맥 조건 → 자모 변형·변환)
5. 겹자음·겹받침 폭 등급과 자동 좁히기
6. 음절 단위 예외 층 + 검수 대기열 (완성형 2,350자 우선)
7. 제작 흐름: 구조 유형별 대표 음절 → 문장 시험 → 일괄 생성
8. 자동 광학 보정: 시각 중심·회색도 균형, 획 충돌 검사
9. 명조 형태소 매개변수 (부리·맺음·꺾임·줄기 끝 삐침·꼭지이응·ㅇ 굵기 각도·대비)
10. 손글씨 모드: 시드 기반 음절별 흔들림 + 탈네모 전환
11. 붓 필압 곡선 (기필 / 행필 / 수필)
12. 내보낼 때 획 합치기(불리언 합집합), 선택적으로 자모 합성 글리프
13. 메트릭 기본값: UPM 1000, em 상자 880/−120, USE_TYPO_METRICS, BASE
14. 이름·OS/2 기본값: 한국어 이름(0x0412), 코드페이지 bit 19, 유니코드 범위 bit, 호환 자모 포함
15. 샘플 기반 스타일 맞추기: 사용자가 쓴 약 28자로 엔진 매개변수를 맞춘다
