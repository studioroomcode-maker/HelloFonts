# HelloFonts

브라우저에서 한글·영문 글꼴을 만들어 **TTF / OTF 폰트 파일**로 저장하는 제작 도구입니다.
고딕 · 명조 · 손글씨 · 붓글씨 · 제목용 등 여러 스타일을 만들 수 있고, **내 손글씨**로도 글꼴을 만들 수 있습니다.

## 특징

- **뼈대 + 스타일 엔진**: 글자를 획의 중심선(뼈대)으로 그리면 굵기·대비·획 끝·필압·부리/맺음·세리프·흔들림을 입혀 외곽선을 만듭니다.
- **한글 11,172자 자동 조합**: 자모 뼈대와 8×4×4벌 문맥 규칙으로 전체 음절을 만듭니다. 특정 배치·벌·음절만 따로 손볼 수 있습니다.
- **손글씨로 만들기**: 원고지를 인쇄해 쓰고 사진을 올리거나 화면에 직접 쓰면, 중심선을 찾아 정리한 뒤 글꼴로 만듭니다.
- **폰트 파일**: TTF(자체 작성기)·OTF, 겹친 획 합치기(Skia PathOps), 한국어 글꼴 이름, 굵기 패밀리(ZIP).
- **로컬 우선**: 서버 없이 동작하며 작업은 브라우저에 자동 저장되고, 프로젝트 파일로 백업할 수 있습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드(dist/)
npm test         # 테스트
```
